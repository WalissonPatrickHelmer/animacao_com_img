# animacao_com_img
Refatoração da interface de scroll de vídeo: centralização do layout com barra de opacidade fixa no meio da tela (z-index estático). Ajuste no posicionamento do contêiner de texto para deslizar suavemente por trás da máscara de leitura, mantendo a sincronia entre a troca de frames das sessões 01 e 02 e a animação vertical durante a rolagem.
